# Extractable UI patterns

## SiteHeader
- Source: `index.html` and `src/css/header.css`
- Category: layout
- Description: fixed site header with logo, navigation and contact CTA.
- Extractable props: active navigation state.

## HeroBanner
- Source: `index.html` and `src/css/hero.css`
- Category: layout
- Description: full-screen photographic hero with content, CTAs and benefits bar.
- Extractable props: active slide and CTA URLs.

## BenefitsBar
- Source: `index.html` and `src/css/hero.css`
- Category: basic
- Description: four-item hero feature strip with Lucide icons.
- Extractable props: none; labels and icon names are hardcoded.
