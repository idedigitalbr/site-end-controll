# Routes

This repository is a static multi-page site. The home route is `index.html`; numbered solution pages are the main secondary routes.

- `/` → `index.html` — home page with hero, about, solutions radar, segments, FAQ and national presence.
- `/1-solucao-engenharia-de-integridade-estrutural.html` → solution detail page.
- `/2-solucao-inspecao-de-ativos-criticos.html` → solution detail page.
- `/3-solucao-ensaios-nao-destrutivos.html` → solution detail page.
