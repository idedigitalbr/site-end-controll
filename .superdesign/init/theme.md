# Theme summary

- Primary navy: `#00215D`
- Cyan accent: `#00c2ff` / `#00abe3`
- Deep background: `#071429` / `#0a1128`
- Body font: Inter/Arimo with system fallbacks.
- CSS approach: vanilla CSS split by section; no Tailwind or component library.
- Main breakpoints: 1200px, 1024px, 992px, 860px, 768px, 480px.

## Source tokens

```css
/* src/css/tokens.css */
```

The source token file is `src/css/tokens.css`; section-specific tokens live in the corresponding `src/css/*.css` files.
